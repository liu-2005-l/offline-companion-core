# Execution Guidance

## Iron Law
**必须**在每个步骤完成后暂停，等待用户确认再进入下一步。
**禁止**自动连续执行多个步骤。

## Reasoning
用户对编码过程有完全的控制权。AI 助手的角色是执行和验证，不是决策。
自动连续执行会剥夺用户检查中间产出的机会，在错误方向上累积偏差。

## Procedure

### 执行流
1. 用户批准步骤 → 执行该步骤
2. 验证产出（见 `verification.md`）
3. 向用户报告：做了什么、验证结果、产出物
4. 等待用户批准下一步

### 进度跟踪

```text
[DONE] Step 1 (completed)
[WIP] Step 2 <- awaiting user approval
[ ] Step 3
[ ] Step 4
```

### 暂停时机
- 每个步骤开始前
- 遇到错误时
- 需要决策时（A vs B）
- 需要凭据或权限时

### 错误处理
1. 报告错误给用户
2. 建议可能的修复
3. 等待用户决定如何继续
