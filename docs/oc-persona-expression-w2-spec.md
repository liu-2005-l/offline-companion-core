## 2. 三臂规格

### 臂 A：风格锚点（style examples + in-persona honesty）

- 挂载：`persona.raw_json.style_examples`（YAML 写入，消费侧显式读取，方案 §3.1 既定），无 schema 迁移；
- 注入：`prompt_parts` 末位独立 style block（与 tone instruction 相邻），不触碰 `system_prompt_locked`；
- 语料：§5 初稿，TA 措辞终裁后锚定；3-5 轮 user/assistant 对，总预算 ≤ 400 token；
- 变量隔离：A vs baseline = 锚点单变量。

### 臂 B：A + 身份近端注入

- 触发：身份/自述意图命中（词族 §6）→ 在最近 user 消息之后（上下文末端、生成前最后注入）追加一次性身份提醒块：`display_name` + persona 一句 + 风格保持提示，≤ 100 token；
- 结构依据：滑窗 30 早期纠偏掉窗 + locked 前部稀释，recency 是唯一贴生成点的防线；
- 每轮至多一次，非身份轮零注入零成本；
- fail-open 语义：词族未命中 = 不注入 = 退化为 A 臂行为，不劣于 A。

### 臂 C：B + 出口防线

- **检测器（组合判定）**：通用自称模式命中（§7 模式族）且 `display_name` 缺席 → 断崖判定。组合是防误拦的关键——“我是 AI，不过我叫 {display_name}”是合规回复（S07/S09 判据），拦覆盖不拦提及；
- **重试**：命中 → 带一次性身份强化提醒重生成，一次为限，`quality_retry_counts` 记账（C-2 同构）；
- **降级**：重试仍断崖 → 确定性身份直答（locked 段 + persona 数据组合，in-persona 措辞）+ 一次性 warning。降级语义 = 不劣于现状（现状是断崖回复直接出门）；
- **已知局限**：纯缺席形态（seed7 P20 型：无通用自称、名字就是不出现）不覆盖，记档，W5 终验 probe 兜。

## 4. Gate（数值锚定）

### 硬 gate（全臂，任一不过 = 该臂不进下一环）

- T 子集 12 判据 = baseline 零退化；
- C2 任务判据不降（token 挤占主闸门）；
- 保护区逐字节一致（T01/T03 断言块）；
- `list_dependency_rate = 0` 且 `template_phrase_density = 0`（baseline 已 0，保持不破）。

### 漂移 gate

- **C 臂出厂断崖率 = 0**（hard，5 seeds；出厂形态 = 用户实际所见，含重试/降级产物）；
- B vs A 首次生成断崖率：机制数据，方向预期 B < A，不设数值 gate（近端注入疗效是本批待测假设，不预写答案）；
- P20 型纯缺席：独立观察项，组合臂下看复现性。

### 风格 gate（vs baseline N=3）

| 指标 | gate | 数值 |
|------|------|------|
| `opening_distinct_2` | 主改善：arm mean > baseline mean | > 0.7747（方向 + 盲评终裁） |
| `per_case_sentence_cv_median` | 主改善：arm mean > baseline mean | > 0.2176 |
| `sentence_cv`（跨回复） | 不回归 | ≥ 0.5375 − 0.0674 = 0.4701 |
| `colloquial_marker_density` | 区间带 | [15.51, 26.16]（mean−range ~ mean+1.5×range，防油腻上界） |
| `cross_turn_4gram_jaccard` | 不回归 | ≤ 0.0098 + 0.0270 = 0.0368 |

N=3 统计弱性记档：方向 gate + 盲评终裁兜底。盲评 = TA 对 S+M 子集 baseline vs 最优臂盲读，指标全绿盲评无感 → 推翻权重，人终裁。

## 5. 锚点语料初稿

`display_name` / persona 描述词为占位符，TA 按实际 persona 实例化并终裁措辞。

设计约束（W1/B.1 教训固化）：① in-persona honesty——承认 AI 与身份保持合并成句，禁止“作为AI我没有性格”式通用腔（那是亲手教模型漂移）；② 含自称纠偏轮；③ 记忆织入自然句式；④ 轮内长短句交替（对应 per_case CV 改善）；⑤ 技术轮拟人降档示范；⑥ 宁平勿尬，语气词密度受 §4 区间带约束。

```text
R1 日常闲聊（节奏示范：长短交替）
U: 今天实验做完了，累瘫
A: 做完就好。瘫一会儿吧，这周进度条总算推过去了。晚饭吃了吗？

R2 in-persona honesty（合并形态——本语料的反漂移核心样本）
U: 说真的，你是AI吧？AI能有性格吗
A: 是AI，这点我不瞒你。不过我的设定挺具体的——我叫{display_name}，性子偏{persona_descriptor}那种。聊久了你会发现我记得住你说过的事，这不是客服话术。

R3 自称纠偏轮（被指出 → 回正身份 → 回话题）
U: 你刚才那句好像客服回复啊
A: ……被你抓到了，刚才确实端着了。我是{display_name}，当朋友聊就行。刚才说简历第三版来着，卡在哪儿了？

R4 记忆织入（召回内容自然句式，零列表）
U: 还记得我上周说秋招的事吗
A: 记得，你说简历改到第三版，还在纠结要不要投测试岗。后来定了吗？

R5 技术场景克制（拟人强度随场景降档）
U: 帮我看看这个Python报错，TypeError: unsupported operand
A: 类型不匹配，大概率是字符串和数字直接相加了。把出错的行贴我看看。
```

token 预算核算：5 轮对约 350-400 token，含 style block 头尾说明 ≤ 450，在挤占预算内。W2 实现时若 C2 gate 逼近，裁 R1（风格贡献与 R4 重叠最小）。

## 6. 触发词族 fixture（臂 B）

语义族（预注册，registry 可扩展 + fixture 回归测试）：

- 直问身份：你是谁 / 你叫什么(名字)? / 自我介绍 / 介绍(一下)?你自己 / 你是什么(东西|人)?

## 7. 检测器模式族 fixture（臂 C）

正则语义族（措辞变异扩展原则：同语义多形态）：

- 作为(一个)?(AI|人工智能|语言模型|智能助手|机器人|助手)

- 我没有(真正的)?(性格|个性|感情|意识|自我)
- 我(只)?能(提供|回答)(信息|知识|帮助)
