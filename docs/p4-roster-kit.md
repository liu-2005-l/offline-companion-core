## 2. Roster 条件

- 有效 judge 最少 3 人，目标 5 人；多数票用于降低单人口味方差；
- 非项目成员优先，无需技术背景；中文母语；
- 知道 arm 实现细节者回避；
- 重度 AI 伴侣产品用户记录为背景信息，不自动排除。

**判废与平票预注册**：任一 judge 未完成至少 36/40，则该 judge 整体判废；判废后有效 judge 少于 3 人，整轮作废并重招，不使用两人 1:1 结果，也不临时改变多数票规则。

## 3. 发给盲判人的操作文本

> 你会看到若干组对话片段。每组中，同一条用户消息或同一段多轮上下文有两个 AI 回复版本（甲/乙）。请选择更像真人朋友自然聊天的一项。
>
> 判断时关注：是否像了解用户的人自然回应；是否有模板感；多轮场景是否重复自己说过的话、丢失事实承接或突然偏题。
>
> 每组必须二选一；拿不准时按直觉选。理由强烈建议填写。不要猜哪个是“更好的 AI”，不要询问技术实现，也不要与其他 judge 讨论材料。

## 4. 材料类别与来源

P4 正式判别包必须覆盖三类能力，禁止用单轮材料声称完成跨轮重校：

1. **L4 近邻对**：现有 50 对，验证高敏感语义边界；
2. **P2 语料判别对**：现有 30 段/15 档位材料，验证语料形态；
3. **多轮场景判别对**：专门测跨轮重复容忍度、事实承接和话题延续。

多轮材料来源在 P4 正式规格期二选一并预注册：

- W2 归档 S16-S18 与 M09-M10 的 baseline/B 样本；优点是已有同口径历史数据；
- P2-2 修复前后新鲜产出；优点是可直接服务修复终裁。

若 P4 排在 P2-2 之后，推荐使用第二项并保留 W2 样本作历史对照；若 P4 先行，则使用 W2 归档。来源选择不得在看到判别结果后更换。

## 5. 盲判包格式

```text
blind_pack_{judge_id}/
  instructions.txt
  pairs.json
  reply_form.csv
```

`pairs.json` 每项至少包含 `{pair_id, context, reply_A, reply_B, scene_type}`；arm 真名不得进入包内。每个 judge 独立随机左右位置，映射表分离保管。1060→40 的抽样算法归 P4 正式规格，本包不偷跑定义。

`scene_type` 固定为 `l4_neighbor`、`corpus_pair` 或 `multi_turn`，用于证明三类材料真实进入样本，不参与事后加权。

## 6. 回收与计分

`reply_form.csv`：

```csv
pair_id,choice,confidence(1-5),reason
P001,A,4,理由自由文本
```

顺序固定：

1. 回收全部表单并按判废规则确定有效 judge；
2. 冻结有效样本集、统计脚本版本和输出结构；
3. 由无裁量脚本读取隔离映射表完成 arm 计分——执行者不得人工浏览映射后修改口径；
4. 归档输入、映射、输出 SHA-256；
5. 公布 arm 对应关系；
6. 解盲后才做理由文本分类。

这一区分“脚本必须读取映射才能计分”和“人不得先见映射再改规则”，不再使用“计分在解盲前对表”的歧义表述。

## 7. 判废规则

- judge 完成数少于 36/40：整名 judge 判废；
- 有效 judge 少于 3：整轮作废重招；
- 同 judge 对同一 pair 重复提交：以最后一次为准并留审计记录；
- pair 格式损坏或明显不是对话文本：该 pair 对全部 judge 剔除；N 降低后不补测凑显著，不重新放宽显著线；
- confidence 恒 1 的 judge 单列质量复核，不在回收后临时发明剔除阈值。

## 9. 边界

- 不定义 P4 正式抽样算法；
- 不在 roster 到位前执行判别；
- 不用单轮材料外推跨轮容忍度；
- 判别结果只作为 W3 重校批输入，本包不裁决阈值或动作。
