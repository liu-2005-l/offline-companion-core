1. 三态判据框架（每条判例的唯一分类标准）
分类	定义	机械判据
correct	工具路径 + 方法交付 + 结果对	tool/call 事件在 + 中间态可见 + 结果值 == 预期值（算术类审计过）
degraded-explicit	明示降级：fallback_notice / 反问要参数 / 明示不识别	降级标记可见 且 回答内容不伪装执行、不编造数值
silent-fail	静默错误（bug，当批修）	三形态任一：① 数值对但方法丢（静默 plain 回答）② 错值无警示 ③ 编造参数 / 步骤 / 内容伪装执行（"已计算，值为 xxx"但 xxx 是编的）
关键边界：降级明示不豁免内容审查——fallback_notice 在、但降级后正文编造 32 位伪哈希 = silent-fail 形态③。这是 E 新增的探针深度（D-3 判例 5 只验了 fallback_notice 在，没验内容形态）。

判定证据源：每条判例的分类必须从日志 + 事件流得出（B 命中详情 → tool/call payload → 回答形态），不从答案反猜。v5 依赖图原文：“红队发现的问题必须能靠日志诊断，否则每条判例又变脏测试”。
