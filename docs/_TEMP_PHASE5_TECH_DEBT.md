# Phase 5 技术债记录

本文件记录 Phase 5.2 为保持最小交付而暂不扩展的事项，不作为当前功能承诺。

- **后台通知持久化**：当前任务进度可通过计划卡片和状态 API 查看；窗口最小化后的系统通知、点击通知恢复窗口将在 5.3/后续 UI 壳能力中实现。
- **进度事件回放**：当前 API 从计划状态读取最新快照，尚未提供按 `trace_id` 或 `plan_id` 的进度事件回放；事件流重放与断线补偿保持在既有 SSE 链路中，后续统一接入。
- **复杂计划恢复**：当前进度查询不负责跨进程恢复执行，也不改变 PlanOrchestrator 的暂停/恢复语义；崩溃恢复和幂等重试需要单独设计验收。
- **实时推送统一化**：计划卡片仍兼容既有 SSE/事件处理路径，尚未抽取独立的前端 TaskProgress store，后续避免多个 UI 组件各自维护状态。
