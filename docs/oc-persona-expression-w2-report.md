## 6. W2-C/F4 裁决

当前裁决：**W2 不发布任何实验臂，三臂数据与失败形态进入 W3**。

1. A 不进 v1.9.0：虽把 baseline 5/5 漂移压到 1/5，仍有 20% 会话出现可感知身份缺席，且 4-gram 超线 8.4%；可靠性优先于局部风格收益。

3. C 不计本轮独立收益：机制在场、判定如实、4/4 离线触发均为真阳性，但运行时输入门仅覆盖 8/370；W3 重设计触发门后再评。
4. A+B 组合臂不跑：现有跷跷板未解，继续铺臂不能消除身份可靠性与跨轮复读的结构问题。
5. 跷跷板判读闭合：A 更偏轮内节奏，B 更偏身份服从，但单靠生成侧无法同时稳定满足；作为 Phase 3 内化论据。
