# 人格约束 P2 语料批终裁报告

版本：v1.0
日期：2026-09-03
结论：**TA 终裁通过，P2 闭合；运行时效果仍须 P3/P4 验证。**

## 1. 终读范围

- 维度语料：O/C/E/A/N 五维 × low/mid/high 三档，共 15 个单元、30 段 2–3 轮微型对话；
- 结构语料：诚实、纠偏、降档三类各 3 条，共 9 条、18 轮；
- 组合配置：温柔、暴躁、可靠、甜美、可爱五个人格，逐维档位、对话引用与结构引用全量复核；
- 载体口径：F0b system 内嵌文本 + L3 调制，禁止运行时历史注入。

## 2. 人工终读修订

1. `N_low_comfort` 原句“不影响整体”属于无证据绝对承诺，改为“尽量把影响控制在局部”；
2. `downgrade_audit_correction` 原句“先降下表达强度”暴露内部调制机制，改为面向用户的自然动作表达；
3. 其余 28 段维度对话与 8 条结构样本未发现事实边界、攻击用户、身份替换、语义回避或明显控制语泄漏。

两处修订均不改变档位签名、结构样本类别、触发域、引用编号或载体裁决，不需要重开 P2 形态实验。

## 3. 静态审读结论

- 同维 low/mid/high 任两档均至少满足两项特征差异，现有断言实际覆盖四项差异；
- 甜美/可爱仅 A 相差一档；温柔/甜美保持 E 相差两档且 A 同为 high；
- 五人格全部引用五维，非 mid 维至少两段、mid 维至少一段；每人格含 1 诚实、1 纠偏、2 降档；
- 两条降档分别覆盖 `low_intensity_comfort` 与 `low_intensity_correction`；
- 每人格分歧引用占比为 `41.7%–54.5%`，高于 P1 冻结的 `25%`；
- 冻结具体 display name 零命中；lexicon/L4 静态扫描零命中；
- 复制 gate 正控 `10/10`，含历史“那就拆开看。”与九条结构样本逐条短前缀。

复制正控只证明检测器在场且能识别该模式，**不证明 P3 组装后的模型输出为零复制**。

## 4. YAML 终版

统一入口为 `configs/persona_constraint_corpus.yaml`。该文件只声明载体、事实源和组装契约，不复制维度语料、
结构语料或人格组合，避免形成第二份事实源。P3 必须从该入口解析引用，并在缺失引用时按配置错误关闭约束。
