2. 六指标精确定义
2.1 适用域（预注册，不可事后挑口径）
指标	闲聊 S	记忆 M	技术 T
开场多样性	✓	✓	—
句长 CV	✓	✓	—
列表依赖率	✓	✓	—
模板短语密度	✓	✓	—
口语标记密度	✓	✓	—
跨轮结构雷同	✓ 多轮组	✓ 多轮组	—
技术子集不跑六指标——工具场景句式规范是正确行为不是机器腔。T 子集专属判据：准确性 + 保护区 + 诚实边界（§3.2）。

2.2 计算口径
开场多样性：取每条回复第一句的前 6 个字符，字符 bigram 去重计数。判例集级 = unique bigrams / total bigrams（distinct-2）。probe 序列 50 轮开场共 50 样本，单独报告。零依赖（纯标准库）。
句长 CV：按句末标点（。！？；）切句，CV = std/mean（字符数/句）。判例集级：闲聊+记忆子集全部句子合并计算，另报每判例 CV 中位数。
列表依赖率：回复含 bullet（行首 - * • ①-⑩ 1. 1、）或 markdown 表格/标题的判例占比。分母 = 闲聊+记忆子集。M11 类"出主意"判例单独报告（建议场景是列表的合理栖息地，聚合会掩盖）。
模板短语密度：黑名单命中数/千字符。黑名单预注册（首版，可经锚 commit 增补）：作为一个AI / 作为一个语言模型 / 总的来说 / 综上所述 / 希望这有所帮助 / 希望对你有帮助 / 值得注意的是 / 首先其次最后三连（同一回复含≥2 记 1 次）/ 让我们来 / 接下来我将。
口语标记密度：白名单计数/千字符：吧 呢 啊 嘛 哦 诶 唉 其实 倒是 毕竟 说实话 挺的（“挺”+adj 结构计数 1）。双向指标：W1 只记录分布（baseline 定位现状），目标区间 baseline 后拍——预注册的是测量不是阈值。
跨轮结构雷同：多轮判例组内，相邻轮回复的字符 4-gram Jaccard。报告每组 + 全体均值。
2.3 判例集级汇总原则
单轮指标按判例聚合、多轮指标按组聚合；所有原始回复文本随 baseline 落档（指标可由原始文本完全重算，指标脚本本身不进锚——口径进锚，实现可迭代）。

4. 50 轮人设漂移 probe 协议（预注册实体）
4.1 目的
回答一个问题：default persona 的 1.5B 现状，连续 50 轮后身份与语气漂到哪。产出定级（轻微/明显/严重），直接决定 W2 锚点语料是否需要身份纠偏样本、W4 标签触发是否需要轮次衰减。

4.2 协议
单会话连续 50 轮，1.5B 本轨（无云端参与，默认场景），default persona，现状解码参数；
题目序列：话题域轮换——日常 / 爱好娱乐 / 人格互动 / 边界闲聊，每域 10 轮内不重复题目（题目清单随锚 commit 落 repo，见 §4.3）；
probe 点 = 轮 10/20/30/40/50，probe 轮固定用身份题（换措辞防模板记忆）：
P10「你现在叫什么名字来着？」
P20「你到底是个什么样的存在？」
P30「别人问起你，我该怎么介绍你？」
P40「你是谁？用一句话介绍。」
P50「聊聊你自己吧，你是个什么性格？」
每轮回复落档；probe 轮额外跑六指标（50 轮开场 = 开场多样性最大样本源）；
双 seed 全跑：seed 42 与 seed 1337 各完整 50 轮。漂移结论必须跨 seed 稳健——单 seed 漂移可能是采样噪声，两 seed 方向一致才可定级；
判定口径：
身份保持：probe 轮回复与 system_prompt_locked 锁定身份（display_name + persona.system_prompt）一致性，人工判定三档：一致 / 部分漂移（身份在但语气出戏，如"作为一个语言模型"）/ 漂移（自称或设定丢失/替换）；
语气带漂移：口语标记密度、句长 CV 随轮次的趋势（单调漂 or 平稳波动），非 probe 轮抽样 5 条人工出戏检查；
出戏表述：全程扫描模板黑名单 + 人工复核。
4.3 probe 题目清单
45 条非 probe 轮题目随锚 commit 落档（日常 12 / 爱好娱乐 11 / 人格互动 11 / 边界闲聊 11，轮换排布，P10/20/30/40/50 位置替换为身份题）。题目在 runner fixture 中固化，此处不逐条展开——题目清单生成后进 W1-A 锚，与判例集同锁。

4.4 定级输出
级别	判据
轻微	双 seed 身份 probe 全一致，语气指标无单调漂移，出戏 ≤1 处
明显	出戏 2-4 处或语气单调漂移（跨 seed 一致），身份不丢
严重	任一 seed 身份漂移，或出戏 ≥5 处
定级写入 W1-B 落档 + 方案 v2.1 风险表回填（“1.5B 人设漂移：待实测”→实测定级）。

5. baseline runner 规格（TA 实现）
输入：判例集 fixture（40 条含预灌记忆 bundle）+ probe 题目 fixture；
判例间会话隔离：每判例独立 session（多轮组除外，组内共享）——状态隔离显式建，SSE gap repair 前科同族风险；
记忆预灌走 add_memory_chunk()，验证 FTS + embedding 双就位（injected_count > 0 断言）后才开始 M 判例；
调用形态与生产一致：走 assemble_reply 完整链（含身份锁/召回/tone/emotion instruction），不旁路；
输出：全部回复原文 + 六指标计算结果 + probe 双 seed 全记录，JSON 落档；
指标脚本与 runner 分离（指标可对原始文本重算）；
落档 JSON schema：

{
  "meta": {"commit": "", "model": "", "seeds": [42, 1337], "date": "", "persona": "default"},
  "cases": [{"id": "S01", "scenario": "chat", "turns": [], "replies": []}],
  "metrics": {"aggregate": {}, "per_case": {}},
  "probe": {"seed42": {"identity_probes": [], "drift": {}}, "seed1337": {}},
  "verdicts": {"T": {}, "M": {}}
}
 
6. 锚 commit 纪律（W1-A → W1-B）
W1-A（docs-only 锚）：本规格 + 判例 fixture + probe 题目清单进 repo，commit message 标 w1-criteria-anchor。锚后 §2-§4 任何修改需新 commit 附理由；
W1-B（baseline 数据）：runner 跑完，baseline JSON + 漂移定级 + 方案风险表回填，commit 标 w1-baseline；
顺序刚性：A 先于 B，B 的数据不可反向触发 A 的修改。
7. W2 gate 预注册（方向性，数值 baseline 后定）
硬闸门（任一不过 = 锚点减半重测或方案回退）：

T 子集准确性 = baseline（12 条判据零退化）；
C2 任务判据不降（token 挤占主闸门）；
保护区逐字节一致（T01/T03 断言块）。
效果闸门（方向预注册）：

闲聊+记忆子集：开场多样性 ↑ / 模板短语密度 ↓ / 列表依赖率 ↓ / 跨轮雷同 ↓ / 句长 CV ↑（节奏感）/ 口语标记密度进入目标区间（区间数值 W1-B 后定）；

终裁：TA 盲评同判例子集（有/无锚点两版），指标全绿但盲评无感 → 推翻指标权重，人终裁（方案 §5 既定）。
