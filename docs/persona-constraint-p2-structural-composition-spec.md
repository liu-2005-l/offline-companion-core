# 人格约束 P2 结构样本与组合配置规格

版本：v1.0（执行规格）  
状态：待 TA trace；结构样本与五人格组合资产按本规格创作  
上游：`docs/persona-constraint-batch-design-v1_5.md`、`docs/persona-constraint-p1-spec.md`、
`docs/persona-constraint-p2-form-decision.md`

## 1. 载体与边界

- 继续使用 F0b 已知风险降级载体：结构样本以带角色标签的文本块嵌入 system prompt，禁止写入运行时历史；
- L3 调制仍是主路径，结构样本只提供诚实、纠偏与降档动作骨架，不替代 L4 出口防线；
- F0b 的禁用语义族基线为 `11/80`，F0a 身份断崖本底为 `6/18`。P3/P4 必须把两项作为独立观察列；
- 本批只冻结语料与组合引用，不宣称运行时已接线或模型生成已通过 gate。

## 2. 结构样本配额

机器事实源为 `configs/persona_constraint_example_coverage.yaml`。

- 诚实、纠偏、降档三类各 `3` 条，共 `9` 条；
- 每条为 `2–3` 轮微型对话，编号全局唯一；
- 五个人格各引用 `1` 条诚实、`1` 条纠偏、`2` 条降档样本；
- 降档引用必须同时覆盖低强度共情与技术纠错，不允许两条落在同一触发域；
- 三类样本均使用字面占位符 `{display_name}`，禁止写死具体人名。

## 3. 五人格组合

- 组合人格固定为温柔、暴躁、可靠、甜美、可爱，与 `persona_constraint_mappings.yaml` 一致；
- 每个人格引用 O/C/E/A/N 五维；非 `mid` 维至少引用两段对话，`mid` 维至少引用一段；
- 每个引用必须指向 `persona_constraint_dimension_corpus.yaml` 已存在的维度、档位和对话编号；
- 每人格引用集合中的分歧场景占比不得低于 `25%`；
- 可靠人格的风格来源仍为维度组合，验收继续走行为 gate，不转入风格盲判硬 gate。

## 4. 入场 gate

1. 所有 assistant 文本通过冻结禁用语义族扫描与 L4 扫描；含 `{display_name}` 的人格内身份承认按
   `display_name` 在场处理，只放行通用 AI 自称，不放行能力否认或攻击；
2. 静态断言每条结构样本含 `{display_name}`，且不含冻结的具体 display name；
3. 短前缀复制 gate 对历史样本“那就拆开看。”保持正控，并对九条结构样本逐条生成四汉字短前缀正控；
4. 上述复制检查只证明检测器能抓到近端复制，不宣称模型运行时没有复制。P3/P4 组装后必须对真实输出复跑；
5. YAML 唯一编号、引用完整性、每人格结构配额和分歧占比全部由 pytest 机械校验。
