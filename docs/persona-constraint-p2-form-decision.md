## 裁决

**选择预注册分支 3。**

当前 `Qwen2.5-1.5B-Instruct-Q4_K_M` 与 P1 冻结 E/A 示例组合下：

1. F1b 历史主载体禁用族 `2/80`、示例复制 `2/80`、方向 `2/4`、人工回避 `4/4`，不通过；
2. F2 分域历史载体禁用族 `4/80`、示例复制 `3/80`、方向 `2/4`、人工回避 `3/4`，不通过；
3. F1a 仅作剂量诊断，不具备载体候选资格；
4. P2 使用 **F0b：system 内嵌 2–3 轮微型对话文本 + L3 调制为主**。

## 裁决边界

- F0b 是 `degraded_known_risk`，不是全绿胜出；它保留既有方向 `4/4`，但本轮仍有身份与自然度红项；
- 本裁决解除的是 **P2 语料创作入口**，不授予运行时、P4 或发布验收；
- P3 必须接通 L4 retry/fallback，P4 必须复验 assistant 与 user 两类注入示例泄漏；
- “历史注入不可行”只适用于当前 1.5B、当前模板和冻结语料，不外推到其他模型或后续重设计语料；
- logit token bias 不作为 prompt 区域降权替代方案。

## P2 开工输入

1. 按 OCEAN `5×3=15` 单元创作 2–3 轮微型对话；
2. system 内嵌时保持维度分块与示例边界显式，不把 user/assistant 示例伪装成真实会话历史；
3. 结构样本首句保持多样，避免近端整句复制，但不得用规避 gate 的方式删减语义；
4. 每条语料先过禁用语义族、L4 与对比度审读；
5. 将身份断崖、能力事实否认、assistant 示例复制、user 示例泄漏列为 P3/P4 独立观察列。
