## 3. 已知假设与验收三腿

### 3.1 跨轮复读

历史嫌疑是上下文中固定形态的重复锚定，但 Q3 实锚显示：B 臂没有专属历史改写；`history` 原样进入 backend，B 仅继承 A 的每轮 style block，并在身份意图轮追加一次性近端提醒。因此“B 臂专属历史注入导致复读”当前证据不足，因果表必须重新定位到：

- 共享 history 形态；
- 每轮重复 style block；
- 记忆块与历史回复共同复述；
- seed/顺序效应，而不是先验认定 B 近端提醒为病因。

### 3.2 聊天单轮 6:8

单轮落后与跨轮复读分开归因。若根因是 B 臂风格代价或事实/诚实问题，结论可以是结构性 trade-off 并显式放弃；不得为了追回单轮比分把 P2 扩成综合风格优化批。

### 3.3 验收信号

修复有效必须同时满足三条：

1. 多轮同口径 4-gram 红消除或显著下降，阈值仍使用现有 0.0368，不在 P2 改线；
2. 聊天单轮盲评不劣化；
3. 多轮盲评 S16-S18 不失守，避免把延续感与复读一起切掉。

盲评触发条件随因果表预注册：修复方向声称改善体验侧时必须盲评；若只声称机械 gate 改善且不改变用户可见文本，矩阵复测即可。禁止在结果出来后用“若需要”追加裁量。

- A：`style_examples_enabled=True`，style block 每轮进入 system prompt；
